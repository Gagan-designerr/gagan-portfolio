# Gagan Naik — Personal Portfolio

A modern, responsive personal portfolio website built with **HTML, CSS, and JavaScript**.

The portfolio showcases my journey as a **B.Tech Computer Science and Engineering student at NMAMIT, Nitte**, along with my projects, skills, and contact information.

## ✨ Features

* Modern minimal portfolio design
* Responsive layout for desktop, tablet, and mobile
* Smooth scrolling navigation
* Scroll-based reveal animations
* Interactive mouse-following background effect
* Dark / Light mode
* Theme preference saved using browser local storage
* Animated project cards
* Clickable phone and email links
* Instagram and LinkedIn links
* Easy-to-edit structure
* No frameworks or complicated dependencies

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, responsive design and animations
* **JavaScript** — Interactions, animations and theme switching

Clone the repository:

```bash

```

Open the project folder:

```bash
cd gagan-portfolio
```

Then open `index.html` in your browser.

For the best development experience, use **VS Code + Live Server**.
